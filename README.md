# 📚 Dalchive (v0.14.0) — 다세계관 아카이브

여러 유명 세계관의 정보를 카테고리로 둘러보거나 검색해서 확인하는
SillyTavern 확장입니다. 기록보관소(아카이브) 컨셉으로 단장했어요.

## v0.14 변경점
1. 이름 변경: Chatdal Pensieve -> **Dalchive** (📚 아이콘)
2. 카테고리 순서 정리
   - 해리포터: 인물 / 주문 / 마법약 / 마법동물 / 마법식물 / 장소
   - 마블: 현행 유지
   - COD: 캐릭터 / 세력 / 무기 / 장비·퍽 / 맵 (게임 카테고리 삭제)
3. 모든 항목 상세에 "📖 위키에서 보기" 링크 추가
   - 표/틀 위주라 설명 추출이 안 되는 항목(예: SAS/Members)도
     이 링크로 원문 위키 페이지를 바로 열 수 있어요.
4. 아카이브 테마 스타일 — 고서 표제(세리프), 금박 괘선, 색인 구분선,
   책등 느낌 세계관 버튼. SillyTavern 라이트/다크 테마에 모두 적응.

## 세계관 (총 3개)

## 사용법
1. 마법봉 메뉴 -> "Dalchive" -> 팝업
2. 세계관 선택 -> 카테고리/검색 -> 항목 클릭 -> 이미지+설명
3. 🌐 번역 (번역 프로필 지정 시 RP와 분리된 API로 번역)
4. 📖 위키에서 보기 (원문 페이지로 이동)
