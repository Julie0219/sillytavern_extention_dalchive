# 📚 Dalchive

여러 세계관의 설정 정보를 SillyTavern 안에서 바로 찾아보는 확장입니다.
롤플레이 중 캐릭터·장소·아이템 같은 설정을 위키에서 검색하고,
한국어로 번역해서 볼 수 있어요.

## ✨ 무엇을 할 수 있나요?

- **세계관별로 둘러보기** — 카테고리(인물·장소·아이템 등)에서 항목을 골라
  설명과 이미지를 봅니다.
- **검색** — 찾는 이름을 영문으로 검색합니다.
- **한국어 번역** — 🌐 버튼 한 번으로 설명을 한국어로 번역합니다.
  (제목도 함께 번역돼요.)
- **원문 보기** — 더 자세히 보고 싶으면 위키 원문 페이지로 바로 이동합니다.

현재 지원 세계관:
- ⚡ 해리포터 (Harry Potter)
- 🦸 마블 (Marvel Universe)
- 🎯 콜 오브 듀티 (Call of Duty)

## 📥 설치 방법

1. SillyTavern을 엽니다.
2. 확장 메뉴(퍼즐 아이콘) → **Install extension**(확장 설치)을 누릅니다.
3. 이 저장소 주소를 붙여넣고 설치합니다.
   - 또는 zip 파일을 받아 `SillyTavern/public/scripts/extensions/third-party/`
     폴더 안에 압축을 풀어 넣어도 됩니다.
4. SillyTavern을 새로고침합니다. (Ctrl + Shift + R)

> 업데이트로 설치가 꼬이면, 기존 `dalchive` 폴더를 지우고 다시 설치한 뒤
> 새로고침하세요.

## 🚀 사용 방법

1. 채팅 화면 아래 **마법봉 아이콘**(확장 메뉴)을 누릅니다.
2. 목록에서 **Dalchive**를 선택하면 창이 열립니다.
3. 세계관을 고릅니다.
4. 카테고리를 누르거나, 위에서 이름을 검색합니다.
5. 항목을 클릭하면 이미지와 설명이 나옵니다.
6. 필요하면:
   - **🌐 번역** — 한국어로 번역
   - **📄 전체 가져오기** — 요약이 너무 짧을 때 전체 내용 불러오기
   - **📖 위키에서 보기** — 원문 페이지 열기

## 🌐 번역 설정 (선택)

번역은 SillyTavern에 연결된 AI를 사용합니다. 기본적으로는 지금 쓰는
연결을 그대로 사용하지만, **번역 전용 연결 프로필**을 따로 지정할 수 있어요.

1. SillyTavern의 **API 연결** 탭에서 번역에 쓸 연결 프로필을 미리 만들어 둡니다.
   (예: 빠르고 저렴한 모델)
2. Dalchive 첫 화면(세계관 선택) 아래 **"번역 프로필"** 드롭다운에서
   그 프로필을 고릅니다.
3. 이제 🌐 번역은 그 프로필로만 동작하며, **롤플레이 중인 메인 연결에는
   전혀 영향을 주지 않습니다.**

## ❓ 자주 묻는 질문

**Q. 토큰(API 비용)이 드나요?**
A. 위키를 검색하고 보는 것만으로는 토큰이 들지 않습니다. 🌐 번역 버튼을
   눌렀을 때만, 번역에 쓰는 AI에 요청이 가서 토큰을 사용합니다.

**Q. 번역을 눌렀더니 롤플레이 연결이 끊기지 않나요?**
A. 끊기지 않습니다. 번역은 메인 연결과 분리되어 동작합니다.

**Q. 어떤 항목을 눌렀더니 설명이 거의 안 나와요.**
A. 일부 항목은 위키에서 표·틀 위주로 작성되어 자동 정리가 어렵습니다.
   그럴 땐 **📖 위키에서 보기**로 원문을 확인하세요.

**Q. 검색이 한국어로는 안 되나요?**
A. 현재는 영문 검색만 지원합니다. (위키 문서 제목이 영어 기준이라서요.)

**Q. 찾는 캐릭터가 목록에 없어요.**
A. 검색으로 직접 찾아보세요. 그래도 없으면 제작자에게 알려주시면
   추가를 검토할 수 있습니다.
