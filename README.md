# 📚 Dalchive (v0.15.0) — 다세계관 아카이브

여러 유명 세계관의 정보를 카테고리로 둘러보거나 검색해서 확인하는
SillyTavern 확장입니다. 모던하고 심플한 디자인.

## v0.15 변경점
1. 디자인을 모던/미니멀로 전면 변경 (산세리프, pill 카테고리, 깔끔한 카드).
2. 상세 화면에 "📄 전체 가져오기" 버튼 — 요약만 보다가 내용이 부족하면
   그 자리에서 바로 전체 문서를 다시 불러옵니다.
3. 검색창 안에 ✕ 버튼 — 검색어를 한 번에 지웁니다.
4. 번역 시 제목도 함께 번역 — "원문 (한글번역)"으로 병기됩니다.
5. (개발자용) OVERRIDES — 표/틀 위주라 설명이 안 나오는 항목이나
   직접 쓴 설명을 보여주고 싶을 때, 코드에 적어두면 위키 대신 그 내용을
   표시합니다. (아래 "개발자 편집" 참고)

## 토큰 안내
- 위키 검색/열람은 Fandom 위키 API를 직접 부르므로 AI 토큰을 쓰지 않습니다.
- 토큰은 오직 🌐 번역 버튼을 눌렀을 때만, 지정한 번역 프로필 API로 들어갑니다.

## ★ 항목(캐릭터 등) 추가하는 법
1. index.js 위쪽의 WORLDS에서 원하는 세계관 -> 카테고리 배열을 찾는다.
2. 그 배열에 '위키 문서 제목', 을 한 줄 추가한다. (따옴표 + 끝에 쉼표)
   예) '🪖 Characters (캐릭터)': [
          'John Price',
          'Captain MacMillan',
          '내가추가할이름',     <- 이렇게 추가
       ],
3. 정확한 위키 제목을 모르면, 확장에서 그 이름을 검색한 뒤 결과로 나온
   제목을 그대로 복사해서 넣으면 됩니다.

## ★ 개발자 편집 (OVERRIDES) — 설명 직접 넣기
표/틀 위주라 추출이 안 되는 항목이나, 내가 쓴 설명을 보여주고 싶을 때
index.js 위쪽 OVERRIDES에 적어둡니다. (배포 시 모두에게 적용됨)

  const OVERRIDES = {
    'Special Air Service/Members': {
      desc: 'SAS의 주요 멤버: 존 프라이스, 고스트, 소프 맥타비시 등.',
    },
    'John Price': {
      title_ko: '존 프라이스 대위',          // (선택) 제목 옆 한글 이름
      desc: '태스크 포스 141의 리더...',       // 보여줄 설명 (필수)
      // img: 'https://...jpg',              // (선택) 위키 대신 쓸 이미지
    },
  };

- desc 가 있으면 그 항목은 위키 대신 이 설명을 보여줍니다.
- title_ko 를 넣으면 제목이 "원문 (한글)"으로 표시됩니다.
- 줄바꿈은 \n 으로 넣습니다.
